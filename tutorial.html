What is OOP?

Object-oriented programming (OOP) is a way of writing code by grouping related data and methods together into classes. Instead of having separate variables and functions scattered everywhere, OOP organizes a program around objects. That makes code easier to read, reuse and update, especially in larger programs like the bank account system we built in class.

Here's a simple example. The Test class stores a string and splits it into words. The printWords method loops through and prints each one. In main, we create an object and call that method on it.

Test.java
public class Test {
    private String str = "hello_my_name_is_zach";
    private String[] words = str.split("_");

    public void printWords() {
        for (String word : words) {
            System.out.print(word + " ");
        }
    }

    public static void main(String[] args) {
        Test t = new Test();
        t.printWords();  // Output: hello my name is zach
    }
}

Common mistakes and how to avoid them

  • God classes. One class that tries to handle everything in the program. Fix: give each class one clear purpose.
  • Ignoring encapsulation. Making every variable public so any part of the program can change it. Fix: keep fields private and use getters and setters to control access.
  • Over-using inheritance. Long chains of parent and child classes that are hard to follow. Fix: only inherit when it is a true "is-a" relationship, like SavingsAccount extends BankAccount.

A world without OOP

Without OOP, programs lean on long lists of separate functions and global variables. In big projects that gets messy fast: functions change data they were never meant to touch, and bugs become harder to find. OOP keeps related code together through encapsulation, so each part of a program interferes as little as possible with the rest.
